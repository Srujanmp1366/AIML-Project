Carbon-Aware Scheduler

A forecast-driven scheduler that shifts delay-tolerant GPU jobs into cleaner hours on the Indian grid, scored against a carbon-agnostic baseline — under both average and marginal emissions accounting.

Matches the team spec’s interface: upload grid_truth.csv (actual CI + MEF) and one or more forecasts_<model>.csv files to drive this from real data. Jobs stay synthetic (Alibaba-trace-like) until the simulator’s own job/results format is finalized.

grid_truth.csv not loaded

Columns: time, actual_ci, mef — one row per hour. Defines the timeline everything else is scored against.

forecasts_<model>.csv not loaded

Columns: issue_time, target_time, predicted_ci. Upload one or more — file name after "forecasts_" becomes the model label. Select multiple files at once.

Upload grid_truth.csv to activate the timeline. A forecast file is optional — without one, the scheduler falls back to a same-hour-yesterday naive forecast.
